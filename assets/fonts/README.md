# FlowvaEditor bundled font library

All selectable font families are self-hosted in this folder. The editor does not request Google Fonts or any other font CDN. Compressed WOFF2 font faces are loaded on demand from the local `assets/fonts/` directory.

The library contains 27 varied families: Inter, Lato, Open Sans, Cabin, Comfortaa, Comic Neue, EB Garamond, Didot, Lobster, Lobster Two, Amiri, DejaVu Sans, DejaVu Serif, DejaVu Sans Mono, Liberation Sans, Liberation Serif, Liberation Mono, Roboto Slab, GFS Neohellenic, Andika, Charis SIL, Gentium, GFS Artemisia, URW Bookman, URW Gothic, Nimbus Sans Narrow, and Chancery.

Package copyright/license notices supplied by the installed font packages are preserved in `licenses/`. Review the applicable notice before redistribution or modification. Existing project-embedded custom fonts continue to load for backward compatibility, but new font uploads are no longer offered.
